# 一键查询排名功能使用说明

## 功能概述

新版本的数据分析系统增加了强大的排名查询功能，支持：

1. **目标下降词一键查询**：自动查询492个目标下降词的百度排名
2. **手动URL查询**：支持手动输入URL进行排名查询
3. **站长之家API集成**：使用专业API获取准确的排名数据

## 功能特点

### 🎯 目标下降词查询
- 自动提取UV大于10且降幅大于50%的目标下降词
- 一键查询多达492个关键词的排名
- 显示详细的流量变化信息（前年UV、今年UV、下降量、下降率）
- 按下降流量排序，优先显示影响最大的词

### 🔍 手动URL查询
- 支持批量输入URL（最多10个）
- 自动提取页面标题作为关键词
- 支持www和m域名的查询

### 📊 详细排名信息
- 百度PC排名位置（页数-条数格式，如"1-3"表示第1页第3条）
- 页面标题和URL
- 域名信息
- 百度收录量
- 查询状态和错误信息

## 使用步骤

### 1. 获取API Key

访问 [站长之家API文档](https://www.chinaz.net/help/834e39f984bf4b9b87e341b2b1b07990) 获取API Key：

1. 注册站长之家账号
2. 购买BD_PC排名查询服务
3. 在买家中心获取API Key

### 2. 进行数据分析

1. 上传当前年度和上一年度的Excel文件
2. 系统自动分析并识别目标下降词
3. 在结果页面找到"一键查询排名"区域

### 3. 配置API

1. 在"API配置"区域输入您的站长之家API Key
2. API Key会以密码形式保护隐私

### 4. 开始查询

#### 目标下降词查询：
1. 点击"一键查询目标下降词排名"按钮
2. 确认查询（会显示要查询的词数）
3. 等待查询完成（每个词间隔1秒，避免API限制）

#### 手动URL查询：
1. 在"手动查询"区域输入URL（每行一个）
2. 点击"查询手动输入URL排名"
3. 等待查询完成

## 查询结果说明

### 结果表格列说明

| 列名 | 说明 |
|------|------|
| 序号 | 查询顺序 |
| URL | 原始URL地址 |
| 标题/关键词 | 页面标题（作为查询关键词） |
| 域名 | 提取的域名 |
| 百度排名 | 排名位置（格式：页数-条数） |
| 收录量 | 百度收录的页面数量 |
| 状态 | 查询状态（正常/错误信息） |
| 流量信息 | 仅目标下降词显示：前年UV、今年UV、下降情况 |

### 排名格式说明

- **"1-3"**：第1页第3条结果
- **"2-5"**：第2页第5条结果
- **"未找到"**：前50条结果中未找到该域名
- **查询失败**：API请求失败或超时

## 注意事项

### API限制
- 每次请求有60秒超时限制
- 查询间隔1秒，避免API限制
- 目标下降词查询最多100个（如超过会自动截取前100个）
- 手动查询最多10个URL

### 查询时间
- 目标下降词查询（492个）预计需要8-10分钟
- 手动查询（10个URL）预计需要10-20秒
- 网络状况会影响查询速度

### 结果准确性
- 排名结果基于百度PC搜索
- 可能因地区、搜索历史等因素有差异
- 建议作为参考数据使用

## 故障排除

### 常见问题

1. **API Key错误**
   - 检查API Key是否正确
   - 确认API服务是否已购买且有余额

2. **查询超时**
   - 检查网络连接
   - 稍后重试

3. **未找到排名**
   - 关键词可能排名在50名之后
   - 页面可能未被百度收录
   - 标题提取可能不准确

4. **查询失败**
   - 检查API Key配置
   - 确认网络连接正常
   - 查看具体错误信息
