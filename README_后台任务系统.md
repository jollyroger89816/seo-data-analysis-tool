# 后台任务系统使用说明

## 概述

新的后台任务系统专为大批量排名查询而设计，支持任务队列管理、失败重试、进度监控等功能。特别适用于需要查询大量关键词排名的场景。

## 🚀 主要功能

### 1. 后台任务执行
- **异步处理**: 任务在后台执行，不会阻塞用户界面
- **持久化**: 任务状态自动保存，服务重启后可恢复
- **队列管理**: 支持多个任务并行执行

### 2. 智能重试机制
- **自动重试**: 查询失败后自动重试，最多重试3次
- **重试间隔**: 重试间隔>70秒，避免API限制
- **失败处理**: 达到最大重试次数后标记为失败

### 3. 任务状态管理
- **实时进度**: 显示任务执行进度和当前查询项
- **状态追踪**: 支持7种任务状态（等待、运行、成功、失败、取消、重试、暂停）
- **任务控制**: 支持任务暂停、恢复、取消、删除等操作

### 4. 任务管理界面
- **可视化监控**: 实时显示任务列表和执行状态
- **统计信息**: 显示各状态任务的数量统计
- **筛选功能**: 按状态筛选任务
- **批量操作**: 支持批量清理旧任务

## 📋 使用方法

### 1. 创建排名查询任务

#### 步骤1: 提取关键词
1. 在排名查询工具主页面，先按正常流程提取关键词
2. 设置过滤条件（如适用）
3. 等待关键词提取完成

#### 步骤2: 选择查询模式
1. 点击"查询排名"按钮
2. 在弹出的查询设置中选择：
   - **实时查询**: 适合少量关键词（<100个）
   - **后台任务**: 适合大量关键词（>100个），支持失败重试

#### 步骤3: 配置任务（后台任务模式）
1. 输入站长之家API Key
2. 选择"后台任务"模式
3. 输入任务名称（可选）
4. 点击"开始查询"

### 2. 任务管理

#### 访问任务管理页面
- 在查询设置页面点击"任务管理"按钮
- 或直接访问：`http://localhost:5002/tasks`

#### 任务状态说明
- **等待中**: 任务已创建，等待执行
- **运行中**: 任务正在执行
- **成功**: 任务执行完成
- **失败**: 任务执行失败（达到最大重试次数）
- **已取消**: 任务被用户取消
- **重试中**: 任务失败后等待重试
- **已暂停**: 任务被用户暂停

#### 任务操作
- **启动**: 开始执行等待中的任务
- **暂停**: 暂停正在执行的任务
- **恢复**: 恢复已暂停的任务
- **取消**: 取消正在执行的任务
- **重试**: 重新执行失败的任务
- **查看结果**: 查看任务执行结果
- **导出**: 导出任务结果为Excel文件
- **删除**: 删除已完成的任务

### 3. 查看任务进度

#### 实时监控
- 任务管理页面每5秒自动刷新
- 显示当前查询的关键词和进度百分比
- 显示成功/失败统计

#### 进度信息
- 总数量和已完成数量
- 当前查询项目
- 执行时间信息
- 错误信息（如有）

### 4. 结果导出

#### 自动导出
- 任务完成后可导出Excel文件
- 包含完整的查询结果和统计信息
- 支持多个工作表（结果+汇总）

#### 结果内容
- 关键词查询结果
- 排名信息（页码+位置）
- 流量数据
- 查询时间和状态
- 错误信息

## ⚙️ 配置说明

### 1. 重试配置
```python
# 默认配置
max_retries = 3        # 最大重试次数
retry_delay = 75       # 重试间隔（秒）
```

### 2. 任务清理
- 默认保留7天的任务历史
- 可手动清理指定天数前的任务
- 自动清理已完成/失败/取消的任务

### 3. 并发配置
- 默认最大并发数：3个任务
- 单个任务内部：顺序执行（避免API限制）
- 查询间隔：1-2秒随机

## 🚨 注意事项

### 1. API限制
- 站长之家API有调用频率限制
- 建议不要同时运行太多查询任务
- 重试间隔设置为>70秒以避免限制

### 2. 资源管理
- 定期清理旧任务避免磁盘空间不足
- 监控内存使用情况
- 合理设置并发数量

### 3. 数据备份
- 重要任务结果请及时导出
- 定期备份任务数据
- 注意数据隐私保护

## 🔍 故障排除

### 1. 常见问题

#### 任务无法启动
- 检查API Key是否正确
- 确认关键词数据是否存在
- 查看任务管理器日志

#### 任务执行失败
- 检查网络连接
- 确认API配额是否充足
- 查看具体错误信息

#### 任务进度不更新
- 刷新任务管理页面
- 检查任务调度器状态
- 重启应用服务

### 2. 日志查看
- 应用日志：`rank_query.log`
- 任务日志：控制台输出
- 错误日志：任务详情中的错误信息

### 3. 性能问题
- 减少并发任务数量
- 增加重试间隔
- 清理旧任务数据
