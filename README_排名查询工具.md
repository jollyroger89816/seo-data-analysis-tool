# 关键词排名查询工具

独立的关键词排名查询工具，支持从分析结果提取关键词、过滤筛选、手动输入URL、批量查询百度排名。

## 功能特点

### 1. 从分析结果提取关键词
- **智能数据源**：自动从最新的 `analysis_results` 目录中读取分析结果
- **目标下降词提取**：提取所有目标下降词的URL和流量数据
- **灵活过滤筛选**：支持按下降量UV和下降率进行精确过滤
- **关键词智能提取**：
  - 优先从页面 meta keywords 标签提取关键词
  - 如果没有关键词，则从页面标题提取
  - 支持多关键词时自动选择第一个
- **实时进度显示**：显示关键词提取进度和当前处理的URL
- **结果预览**：提取完成后可预览所有关键词和状态
- **状态分类**：成功/使用标题/无关键词/失败

### 2. 过滤筛选功能 ⭐ 新增
- **下降量UV过滤**：设置最小和最大下降量范围
- **下降率过滤**：设置最小和最大下降率范围（百分比）
- **统计信息查看**：查看完整的数据分布统计
- **预览过滤结果**：实时预览过滤条件的结果数量
- **智能建议**：根据数据分布提供过滤条件建议
- **灵活组合**：支持多种过滤条件的组合使用

### 3. 批量排名查询
- **基于提取结果**：使用提取的关键词进行批量排名查询
- **站长之家API**：使用站长之家开放平台API查询百度排名
- **智能关键词选择**：自动选择最佳关键词进行排名查询
- **实时进度监控**：显示查询进度和当前查询的关键词
- **详细结果**：包含排名、标题、URL、收录量等信息

### 4. 手动URL查询
- **灵活输入**：支持手动输入URL列表
- **自动关键词提取**：自动提取每个URL的关键词
- **即时查询**：立即返回排名查询结果

### 5. 结果导出
- **关键词导出**：导出关键词提取结果为Excel文件
- **排名结果导出**：导出排名查询结果为Excel文件
- **详细汇总**：包含统计信息和详细数据

## 使用方法

### 启动工具
```bash
# 进入数据分析目录
cd 数据分析

# 启动排名查询工具
python rank_query_app.py

# 或使用启动脚本
./start_rank_query.sh
```

### 使用步骤

#### 1. 查看分析结果和统计信息
1. 打开工具页面：http://localhost:5002
2. 点击"检查分析结果"查看最新分析数据
3. 点击"查看统计"了解数据分布情况

#### 2. 设置过滤条件（可选）
1. 根据统计信息设置下降量UV范围
2. 设置下降率范围（50%-100%）
3. 点击"预览过滤结果"查看筛选后的数量
4. 根据需要调整过滤条件

#### 3. 提取关键词
1. **提取全部**：点击"提取全部目标下降词关键词"
2. **按条件提取**：点击"按条件提取关键词"（推荐）
3. 等待提取完成，查看提取结果

#### 4. 查询排名
1. 在关键词提取结果中点击"查询排名"
2. 输入站长之家API Key
3. 点击"开始查询"
4. 等待查询完成，查看排名结果

#### 5. 导出结果
1. 关键词提取完成后可点击"导出关键词"
2. 排名查询完成后可点击"导出结果"
3. 文件会自动下载到本地

## 过滤功能详解

### 统计信息
工具会自动分析目标下降词的数据分布：
- **下降量UV统计**：最小值、最大值、平均值、中位数
- **下降率统计**：范围分布、平均值等
- **分布图表**：不同范围的数据数量分布

### 过滤条件设置
- **下降量UV过滤**：
  - 最小下降量：例如设置1000，只提取下降量≥1000的数据
  - 最大下降量：例如设置50000，只提取下降量≤50000的数据
- **下降率过滤**：
  - 最小下降率：例如设置70%，只提取下降率≥70%的数据
  - 最大下降率：例如设置90%，只提取下降率≤90%的数据

### 过滤示例
根据实际数据分析，以下是一些常用的过滤条件：

1. **高价值下降词**：
   - 下降量UV：1000 - 10000
   - 下降率：70% - 90%
   - 结果：约769个高质量目标

2. **极高下降词**：
   - 下降量UV：5000+
   - 下降率：80%+
   - 结果：约122个极高价值目标

3. **中等下降词**：
   - 下降量UV：100 - 1000
   - 下降率：60% - 80%
   - 结果：约15000个中等价值目标

### 智能建议
系统会根据数据分布自动提供过滤建议：
- 下降量建议范围：基于平均值的0.5-2倍
- 下降率建议范围：基于平均值的0.8-1.2倍

## 数据源说明

### 分析结果文件
- **位置**：`数据分析/analysis_results/` 目录
- **格式**：JSON格式，包含完整的分析结果
- **选择**：自动选择最新的已完成分析结果（.done文件）
- **内容**：包含目标下降词的URL、流量数据等信息

### 目标下降词条件
- **UV条件**：去年UV > 10
- **降幅条件**：下降幅度 > 50%
- **数据来源**：从 `target_decline_details_full` 或 `target_decline_details` 字段提取
- **总数量**：33,630个目标下降词

## 关键词提取逻辑

### 提取优先级
1. **Meta Keywords**：优先从页面的 `<meta name="keywords">` 标签提取
2. **页面标题**：如果没有关键词标签，则从 `<title>` 标签提取
3. **多关键词处理**：如果有多个关键词（逗号分隔），自动选择第一个
4. **标题清理**：自动去除"东奥会计在线"等网站后缀

### 提取结果状态
- **成功**：成功从meta keywords提取到关键词
- **使用标题**：没有关键词标签，使用页面标题
- **无关键词**：无法提取到有效关键词，使用ID作为关键词
- **失败**：网络错误或其他异常

## API接口

### 获取分析信息
```
GET /api/get_analysis_info
```

### 获取过滤统计信息
```
GET /api/get_filter_statistics
```

### 预览过滤结果
```
POST /api/preview_filter
Content-Type: application/json
{
  "min_decline_uv": 1000,
  "max_decline_uv": 10000,
  "min_decline_rate": 70,
  "max_decline_rate": 90
}
```

### 提取关键词
```
POST /api/extract_from_analysis          # 提取全部
POST /api/extract_with_filter            # 按条件提取
```

### 查询进度
```
GET /api/extract_progress/<session_id>
GET /api/query_progress/<session_id>
```

### 获取结果
```
GET /get_extract_results/<session_id>
GET /get_query_results/<session_id>
```

### 导出功能
```
POST /export_keywords
POST /export_results
```

## 注意事项

1. **数据依赖**：需要先运行主数据分析工具生成分析结果
2. **过滤策略**：建议根据统计信息合理设置过滤条件，避免过度筛选
3. **API限制**：站长之家API有查询频率限制，建议适当控制查询速度
4. **网络超时**：关键词提取可能因网络问题超时，工具会自动重试
5. **内存使用**：大量URL查询时注意内存使用情况
6. **结果保存**：查询结果仅在会话期间保存，建议及时导出

## 故障排除

### 常见问题
1. **没有分析结果**：确保已运行主数据分析工具
2. **过滤结果为空**：检查过滤条件是否过于严格
3. **API Key错误**：检查站长之家API Key是否正确
4. **网络超时**：检查网络连接，或增加超时时间
5. **关键词提取失败**：可能是目标网站反爬虫机制，可手动输入关键词
