# 关键词查询功能使用说明

## 功能概述

系统现在支持从最新的Excel分析报告中自动提取目标下降词，并使用每个URL页面的keywords标签进行排名查询。

## 主要特性

### 🔍 **智能关键词提取**
- 自动从URL页面的`<meta name="keywords" content="...">` 标签中提取关键词
- 如果没有keywords标签，自动使用页面标题作为备用关键词
- 支持关键词格式清理和优化

### 📊 **实时进度跟踪**
- 显示详细的查询进度（提取关键词、查询排名）
- 实时显示当前处理的URL和完成百分比
- 支持后台异步处理，不阻塞用户界面

### ⚡ **超时优化处理**
- 关键词提取设置8秒超时，避免长时间等待
- API查询设置30秒超时，确保稳定性
- 失败URL自动跳过，不影响整体进度

### 🎯 **多种查询模式**
1. **Excel报告查询**: 自动识别最新分析报告中的目标下降词
2. **目标下降词查询**: 查询当前会话的目标下降词
3. **手动URL查询**: 支持手动输入URL进行查询

## 使用步骤

### 1. 准备工作
- 确保已完成数据分析，生成了Excel分析报告
- 获取站长之家API Key（[获取地址](https://www.chinaz.net/help/834e39f984bf4b9b87e341b2b1b07990)）

### 2. 启动查询
1. 在结果页面找到"排名查询功能"区域
2. 输入站长之家API Key
3. 点击"查询最新Excel报告中的目标下降词"按钮
4. 确认查询（系统会提示查询数量和预估时间）

### 3. 监控进度
- 系统会显示实时进度条
- 显示当前状态：
  - `正在初始化查询...`
  - `正在提取关键词 (X/Y) Z%`
  - `正在查询排名 (X/Y) Z%`
  - `查询完成，正在获取结果...`

### 4. 查看结果
查询完成后，系统会显示包含以下信息的表格：
- **序号**: 查询顺序
- **URL**: 原始页面地址
- **关键词**: 从页面提取的关键词
- **域名**: 提取的域名信息
- **百度排名**: 在百度搜索中的排名位置
- **收录量**: 百度收录的页面数量
- **状态**: 查询状态（正常/错误信息）
- **流量信息**: 包含去年UV、今年UV、下降流量等

## 技术特点

### 关键词提取逻辑
```python
# 优先级顺序：
1. meta keywords标签内容
2. 页面title标题（去除网站后缀）
3. 使用ID作为备用关键词
```

### 超时设置
- 关键词提取：8秒超时
- API排名查询：30秒超时
- 进度轮询：每2秒更新一次

### 查询限制
- 最多同时查询100个URL
- 每次API调用间隔1秒，避免频率限制
- 支持错误恢复和跳过机制

## 注意事项

1. **API配额**: 站长之家API有调用次数限制，请合理使用
2. **查询时间**: 100个URL大约需要3-5分钟完成
3. **网络稳定性**: 确保网络连接稳定，避免查询中断
4. **关键词质量**: 系统会自动优化关键词格式，但页面质量影响提取效果

## 故障排除

### 常见问题
1. **"没有找到Excel分析报告"**
   - 解决方案：先完成数据分析，确保生成了Excel报告

2. **"API Key无效"**
   - 解决方案：检查API Key是否正确，确认账户余额充足

3. **查询中断**
   - 解决方案：刷新页面重新开始，系统会自动识别最新报告

4. **部分URL查询失败**
   - 原因：网络超时或页面无法访问
   - 影响：不影响其他URL的查询结果

### 性能优化建议
- 选择网络状况良好的时间段进行查询
- 避免同时运行其他网络密集型任务
- 如需查询大量URL，建议分批次进行
